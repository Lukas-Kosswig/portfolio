# lukas-kosswig.de

Persönliche Portfolio-Website, live unter [lukas-kosswig.de](https://lukas-kosswig.de).

## Stack

- HTML / CSS / JavaScript (vanilla, kein Framework)
- Schriften: Inter + JetBrains Mono via Google Fonts
- Hosting: Raspberry Pi mit nginx und Let's Encrypt SSL

## Struktur

```
index.html   Markup
style.css    Styles
script.js    Scroll-Reveal per IntersectionObserver
```
